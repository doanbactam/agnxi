# Product

## Register

product

## Users
Developers who use at least one AI coding agent (e.g., Claude Code, Codex CLI, Gemini CLI, OpenCode) and want to optimize their setup with context-specific MCP servers, skills, configurations, and models.

## Product Purpose
AIStack is the "roadmap.sh for AI coding". It allows developers to select a coding agent and immediately discover recommended helper tools, configs, models, and combos. It serves as a structured, copy-pasteable configuration catalog.

## Brand Personality
Neo-Mirai (cyber-minimalist). Deep black lacquer ground, ultra-fine gold hairlines, and gold leaf (kinpaku) active buttons. Clean, sharp, technical, and hyper-premium.

## Anti-references
- Standard dark mode with blue/purple/neon-green glow elements.
- Soft grey cards with standard drop shadows.
- Cream or warm-neutral SaaS landing pages.
- Tracked uppercase eyebrows above every section.
- Left-border colored stripes on cards or code blocks.

## Design Principles
1. **Utility First**: Visually emphasize immediate actions, snippets, and clean code blocks. Decoration is cut.
2. **Contextual Layout**: Ensure that relationships between agents, models, MCPs, and skills are immediately obvious.
3. **Keyboard and Terminal Oriented**: Layouts should mimic terminal outputs (clean layouts, monospace details, subtle borders).

## Accessibility & Inclusion
- Contrast of at least 4.5:1 for all text.
- Full keyboard navigate-ability.
- Strict respect for `prefers-reduced-motion`.
